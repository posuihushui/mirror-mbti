## 兼容与数据

- 迁移 `0002_oval_dagger.sql` 增加问卷 ID、题数、题目 ID 答案、计分版本和报告版本，已应用于本地数据库。部署时需先应用同一迁移。
- 原 32 题的内容、顺序和计分规则保持冻结，旧数字数组接口继续可用。旧记录链接、原始分数与已购访问权益保留。
- 64 题新增 32 个原创场景，并在新版本内调整 4 个旧条目的表述；这不修改轻量版。答案按题目 ID 校验，拒绝重复、遗漏、跨版本或未知题目。
- 检查已提交答案只对归属访客开放，重新提交生成新结果；不会覆盖原记录。恢复订单身份切换到对应用户，不合并两个匿名身份。
- 内部为兼容保留平分字母规则，界面与公开 API 不将它当作确定类型。50–60% 是解释规则，不是统计置信区间。

## 验证与后续

已通过类型检查、lint、97 项单元测试、生产构建，以及手机/电脑共 54 项浏览器测试。最后统一示例页的 32/64 题说明后重新构建，针对首页、示例与公开帮助页的 18 项复查也全部通过。原报告历史和订单恢复的安全边界继续通过验证。

64 题是原创体验版本，尚无理解访谈、真实完成率和心理测量学验证数据；两版分数未做等值校准。预计 5 分钟和 8–10 分钟需要试测校正。按审查建议，96 题与同题数 A/B 版本留待理解访谈和试测后决定，未使用随机抽题制造版本。

真实微信支付、微信内置浏览器、安全区和屏幕阅读器仍需对应环境验收；本次自动测试不替代这些检查。
