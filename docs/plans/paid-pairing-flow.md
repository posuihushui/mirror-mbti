# 分享与付费双人指南：流程评审图

更新：2026-09-17  
依据：[产品与实施规格](./paid-pairing-product.md) · [实施提示词](./paid-pairing-execution-prompt.md)

**这是待实施方案，不代表线上功能已完成。** 图中按当前规格默认：**双方分别解锁各自用于配对的报告；单人相处说明书免费**。双付费是设计默认值，尚未获得用户单独确认；若改为仅发起者付费，须同步修改主规格和以下全部对应流程。

## 1. 一页总览

先看两人怎样从「看到价值」走到「拿到指南」。此图聚焦成功路径，未购买、不同意、失败及历史数据见后面的分支图。

![付费双人相处指南主流程](./paid-pairing-flow/overview.png)

[打开可放大的矢量图](./paid-pairing-flow/overview.svg)。图中文字和详细逻辑以本文件与主规格为准；总览图更新时须同步维护。

**评审要点：**

- 付款前能看具体沟通示例及费用规则；已购结果可以直接使用。
- 发起者从结果页、报告页或我的报告进入，无需先公开单人卡。
- 发起者先确认公开范围，好友再单独确认参与；支付不替代任何一次同意。
- 真实产物是三段私密沟通指南：可能容易理解的地方、需要说清楚的地方、下次可以怎么说。

## 2. 免费单人分享与付费配对的分流

```mermaid
flowchart TD
    R["本人完成测试<br/>正常阅读免费结果"] --> W{"这次想做什么？"}
    W -->|分享自己| S["免费生成单人相处说明书<br/>四条候选中选三条"]
    S --> SP["预览公开范围<br/>类型与四维标签默认不公开"]
    SP --> SC{"确认公开？"}
    SC -->|否| SX["保留私密<br/>不生成公开链接"]
    SC -->|是| SO["生成独立公开卡<br/>保存图片或复制链接"]
    SO --> SV["好友阅读公开卡<br/>可开始自己的免费测试"]
    W -->|一起理解彼此| P["查看双人指南示例<br/>了解双方付费规则"]
    P --> PE["检查所选结果权益<br/>进入发起者流程"]
```

单人卡不是配对的必经步骤；单人卡的公开同意也不授权配对。复制、下载只是用户操作，不能标成「好友已收到」或「分享成功」。

## 3. 发起者：介绍 → 解锁 → 邀请

```mermaid
flowchart TD
    A0["本人结果页／报告页／我的报告"] --> A1{"所选结果已解锁？"}
    A1 -->|是，含历史已购| A5["显示：邀请一个人"]
    A1 -->|否| A2["展示功能示例与权益<br/>告知双方分别解锁对应报告"]
    A2 --> A3{"这份结果允许购买？"}
    A3 -->|全均衡，暂不提供付费| AF["保留免费概览与单人说明书<br/>不开放配对购买"]
    A3 -->|允许| A4{"选择解锁？"}
    A4 -->|暂不| AF
    A4 -->|解锁| AP["沿用现有支付流程"]
    AP --> AS{"服务端确认结果权益？"}
    AS -->|未付款／失败| AR["继续阅读或重试支付"]
    AR --> AP
    AS -->|付款已确认，权益同步中| AQ["重试核对权益<br/>禁止重复购买"]
    AQ --> AS
    AS -->|已解锁| A5
    A5 --> A6{"该结果已有有效邀请？"}
    A6 -->|有| AL["继续使用原邀请<br/>保留原公开快照"]
    A6 -->|没有| A7["预览将公开的四维类别<br/>问卷版本与测试日期"]
    A7 --> A8{"单独同意公开？"}
    A8 -->|否| AX["不创建邀请<br/>个人报告仍可读"]
    A8 -->|是| A9["服务端核对本人及权益<br/>创建邀请，有效期 30 日"]
    A9 --> AL
    AL --> A10["预览／复制链接与话术<br/>用户自行发送给好友"]
    A10 --> A11["在我的双人指南回访<br/>等待好友明确同意"]
```

**入口与范围：**

- 权益属于这份结果。买过其他报告不代表本次已解锁；历史已购的全均衡结果也可以使用。
- 公开邀请中只有发起者同意的定性信息，不含原结果链接、答案、分数、订单号或完整报告。
- 每份结果最多一条当前有效邀请。同一邀请可以让不同好友各自形成独立指南，不出现公开成员列表。
- 「关闭并重新邀请」必须确认会关闭旧邀请下全部指南；不能为换链接而静默关闭。

## 4. 好友：知道费用 → 自己的结果 → 再次同意

```mermaid
flowchart TD
    B0["好友打开邀请链接"] --> B1{"已参加这份邀请<br/>且指南仍有效？"}
    B1 -->|是| BR["直接回访自己的指南<br/>不重复付款或同意"]
    B1 -->|否| B2{"邀请可供新加入？"}
    B2 -->|关闭／到期／旧制／已撤回| BX["说明无法继续<br/>原个人报告与历史阅读权保留"]
    B2 -->|有效的新制邀请| B3["先看价值示例、公开范围和费用<br/>双方均需解锁对应报告"]
    B3 --> B4{"使用哪份本人结果？"}
    B4 -->|已有结果| B5["选择本人结果<br/>可查看正常个人结果"]
    B4 -->|没有／希望重新测试| B6["免费选择问卷并完成测试<br/>先正常呈现自己的结果"]
    B6 --> B5
    B5 --> BC["保存本次续接意图<br/>尚未向发起者共享资料"]
    BC --> B7{"所选结果已解锁？"}
    B7 -->|已解锁| B11["预览自己的共享范围<br/>仅向邀请发起者展示"]
    B7 -->|未解锁| B8{"允许购买且愿意解锁？"}
    B8 -->|全均衡／暂不购买| BF["继续免费阅读或单人分享<br/>不生成这次双人指南"]
    B8 -->|愿意且允许| B9["购买自己的完整报告与配对资格"]
    B9 --> B10{"服务端确认结果权益？"}
    B10 -->|未付款／失败| BP["保留续接，可重试支付<br/>发起者看不到支付状态"]
    BP --> B9
    B10 -->|权益同步中| BS["校验重试<br/>不重复购买"]
    BS --> B10
    B10 -->|已解锁| B11
    B11 --> B12{"明确同意生成？"}
    B12 -->|否| BN["不加入、不共享自己的信息<br/>完整个人报告仍可阅读"]
    B12 -->|是| BV{"服务端再次校验<br/>双方权益、本人身份与邀请状态"}
    BV -->|无效／无权| BX
    BV -->|通过| BO["冻结生成三段双人指南<br/>仅发起者与该好友可读"]
    BO --> BR
```

- 好友先知道费用，再决定是否测试；不能做完才第一次看到收费要求。
- 新测试必须先展示自己的正常结果，不能提交后直接配对。
- 同一邀请、同一参与者重复请求返回原指南；已撤回的指南不能通过重新提交复活。
- 付款、身份恢复、保存续接意图都不是同意参与；提交前和事务中仍须重新校验。

## 5. 支付回跳与多个邀请

```mermaid
flowchart TD
    C0["支付成功返回／稍后回访"] --> C1{"当前浏览器有原身份？"}
    C1 -->|没有| C2["通过现有订单恢复身份<br/>完整刷新后再继续"]
    C2 --> C3
    C1 -->|有| C3["读取本人、该结果的服务端续接记录"]
    C3 --> C4{"还有几条有效待办？"}
    C4 -->|一条| C5["显示：继续这次配对"]
    C4 -->|多条| C6["本人选择要继续的邀请<br/>不静默选择最近一人"]
    C6 --> C5
    C4 -->|没有| C7["阅读个人报告／发起自己的邀请<br/>已失效则明确说明"]
    C5 --> C8["进入好友公开范围确认<br/>再明确同意，最终服务端复核"]
    C3 -.->|已生成的记录| C9["查看原指南<br/>已完成记录不再当作待办"]
```

**支付中邀请到期或撤回：**自己的报告权益保留，原邀请不能继续。不能自动复活邀请、换配其他人、替好友确认或让用户重复购买。已有指南的回访以未撤回为前提，邀请单纯到期不影响它。

## 6. 到期、撤回与历史内容

```mermaid
flowchart TD
    D0["资源发生状态变化"] --> D1{"发生了什么？"}
    D1 -->|邀请满 30 日| D2["停止新加入<br/>已生成且未撤回的指南继续可读"]
    D1 -->|任一方撤回某份指南| D3["该份指南对双方关闭<br/>其他配对不受影响"]
    D1 -->|发起者关闭邀请| D4["停止新加入<br/>该邀请下全部指南关闭"]
    D1 -->|关闭关联的单人卡| D5{"邀请是否显式关联该卡？"}
    D5 -->|是| D4
    D5 -->|独立邀请| D6["邀请与指南不受该卡关闭影响"]
    D1 -->|旧免费邀请| D7["不再接受新参与者<br/>发起者需按新规则重新创建"]
    D1 -->|旧免费已生成指南| D8["原双方继续阅读与撤回<br/>不补款、不自动重算内容"]
```

以上变化都不删除个人测试或已购报告。不能通过批量撤销旧邀请来实现商业升级，否则会误关闭需要保留的历史指南。

## 7. Review 时逐项核对

| 检查点 | 图中的预期 |
| --- | --- |
| 用户在何时理解价值？ | 付款前看到具体沟通示例，好友测试前也能看到 |
| 谁需要付费？ | 当前默认双方分别解锁所选报告，已购不用再买 |
| 免费分享还在吗？ | 保留独立的单人说明书支线 |
| 付款后哪里进入？ | 结果页、报告页、我的报告直接邀请，无需先公开单人卡 |
| 是否误把付款当同意？ | 发起者公开同意与好友参与同意各有独立节点 |
| 发起者能看到好友哪些信息？ | 只有好友同意后的类别与指南，看不到未同意资料或付款状态 |
| 失败后是否还有自己的报告？ | 支付买到的个人报告保留，失效邀请不自动复活 |
| 是否保留历史承诺？ | 旧已生成指南仍可读，旧邀请停止新增 |

业务规则以主规格为准；本文件用于评审流程，不新增独立接口或收费决策。详细分支使用 Mermaid 保存，便于后续随需求维护。
